# 경제 뉴스 MCP 서버: 매일 아침 경린이의 경제신문

> 한 줄 요약: **도구가 신문을 가져다주고, Claude가 쉽게 풀어 읽어 주고, 나는 한 줄만 남긴다.**

[HR 저장소의 hr-news](https://github.com/dhcoaud98/HR/tree/main/hr-news)를 경제 공부용으로 바꾼 버전입니다. 주제를 **금리, 물가·성장, 환율·증시** 세 가지로 고정하고, 매일 읽은 것을 쌓아 가는 공부노트 기능을 그대로 가져왔습니다.

## 파일

| 파일 | 내용 |
|---|---|
| `server.py` | 도구 4개 + Prompt 1개 |
| `test_client.py` | 자동 테스트 (뉴스는 인터넷 필요) |
| `공부노트.md` | `save_reading`을 쓰면 생기는 나만의 기록 (`.gitignore`로 로컬에만 저장) |

## 도구 한눈에 보기

| 이름 | 종류 | 하는 일 |
|---|---|---|
| `econ_news` | Tool | 한 주제의 최신 기사 (사전에 없는 단어도 검색) |
| `econ_briefing` | Tool | 세 주제를 한 번에, 겹치는 기사는 한 번만 |
| `save_reading` | Tool | 기억할 기사를 "내 말로 이해한 것"과 함께 공부노트에 저장 |
| `list_readings` | Tool | 최근 N일 공부 기록 보기 (주간 복습용) |
| `daily_econ_reading` | Prompt | 매일 아침 10분 읽기 루틴 양식 |

주제별 검색어는 `TOPICS`에 있습니다. `OR`로 비슷한 말을 묶어 두었고, 한 줄만 추가하면 주제가 늘어납니다.

```python
TOPICS = {
    "금리": "기준금리 OR 한국은행 OR 금통위 OR 연준 금리",
    "물가·성장": "소비자물가 OR 경제성장률 OR GDP OR 경기 전망",
    "환율·증시": "원달러 환율 OR 코스피 마감 OR 외국인 순매도",
}
```

## 매일 쓰는 법 (10분 루틴)

1. Claude Desktop 입력창의 도구 메뉴에서 **`daily_econ_reading`** 양식을 고릅니다.
2. Claude가 `econ_briefing`으로 기사를 가져와 주제별로 1개씩 골라 줍니다. 각 기사마다 쉬운 요약, 금리·물가·환율 중 무엇과 연결되는지, 어려운 용어 한 줄 뜻, "내 돈에는?" 질문이 붙습니다.
3. 마음에 드는 것 하나를 저장합니다. 이때 **요약이 아니라 내 말로 이해한 것**을 한 줄 적는 게 포인트입니다.
4. 금요일에는 "이번 주 공부노트 보고 정리해 줘" → `list_readings`로 한 주를 돌아봅니다.

## 이렇게 물어보세요

| 이럴 때 | Claude에게 이렇게 | 쓰이는 도구 |
|---|---|---|
| 브리핑에서 본 소식의 다른 기사가 궁금함 | "기준금리 관련 뉴스 최근 7일 것만 보여 줘" | `econ_news` |
| 세 주제를 한 번에 훑기 | "오늘 경제 뉴스 브리핑해 줘" | `econ_briefing` |
| 관심 주제 따로 찾기 | "반도체 수출 뉴스 3개만 찾아 줘" | `econ_news` |
| 기억하고 싶은 소식이 생김 | "이 기사 공부노트에 저장해 줘. 메모는 '외국인이 팔면 환율이 오른다'" | `save_reading` |
| 한 주를 돌아보기 | "이번 주 공부노트 보고 정리해 줘" | `list_readings` |

## 실행

```bash
cd econ-news
uv sync                 # 패키지 설치 (처음 한 번)
uv run test_client.py   # 도구를 차례로 호출해 결과 출력 (뉴스는 인터넷 필요)
```

인터넷이 막혀 있으면 오류 대신 "뉴스를 가져오지 못했어요" 문장이 나오면 정상입니다.
