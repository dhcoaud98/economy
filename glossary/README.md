# 📖 경제 용어집

매일 브리핑에 나온 용어 중 **처음 보는 분야 용어만** 골라 쌓는 나만의 용어집입니다.
단어 공부로 산으로 가지 않도록, 모든 용어에 **꼭 알기 / 대충 알기 / 몰라도 됨** 판정을 붙였습니다.

- 전체 15개 · 공부할 용어 15개 (🔴 6 · 🟡 6 · ⚪ 3) · 한동안 안 나온 용어 0개 · 이제 아는 용어 0개
- 기록 기간: 2026-11-20 ~ 2026-11-20 (1일)

## 읽는 법

| 판정 | 의미 |
|---|---|
| 🔴 꼭 알기 | 경제 뉴스에 계속 나옵니다. 뜻과 '왜 중요한지'까지 읽어 두세요. |
| 🟡 대충 알기 | 한 줄 뜻만 알면 기사를 읽는 데 지장 없습니다. |
| ⚪ 몰라도 됨 | 넘어가도 됩니다. 걸리면 그때 한 줄만 보세요. |

- 같은 용어가 **3일 나올 때마다 한 단계씩 자동으로 올라갑니다.** 자주 나오면 알아 둘 때가 된 것입니다.
- ⚪ 용어가 **30일 넘게 다시 안 나오면 아래로 자동으로 접힙니다.** 다시 나오면 목록에 돌아옵니다.
- 다 익힌 용어는 매주 금요일 올라오는 **[용어집 주간 체크](https://github.com/dhcoaud98/economy/issues?q=label%3A%EC%9A%A9%EC%96%B4%EC%A7%91)** Issue에서 체크하면, 다음 날 아침 '이제 아는 용어'로 옮겨집니다.

- 매일 새로 나온 용어: [`daily/`](daily/) (날짜별 파일)
- 원본 데이터: [`terms.json`](terms.json)
- 분야: 기초 개념 / 시장·가격 / 성장·경기 / 물가 / 금리·통화 / 환율·무역 / 금융·투자 / 정책·기관
